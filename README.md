# Portly

一个小巧的 macOS 菜单栏 SSH 隧道工具。为两个常用连接提供独立开关、连接状态和清晰的错误提示，复用你已有的 SSH 配置。

原生 SwiftUI 界面，无插件或第三方依赖。支持 macOS 12 及以上，发布构建兼容 Apple 芯片与 Intel Mac。

## 功能

- 在紧凑窗口或菜单栏中连接、断开隧道。
- 自定义本地端口，自动检查两个连接之间的端口冲突。
- 通过弹窗输入密码、私钥口令或二次验证码，不保存认证信息。
- 展示配置、认证、网络、主机密钥及端口占用等错误，支持选中和复制。
- 识别已有的相同 SSH 转发，避免重复建立连接。
- 关闭窗口继续运行，退出 App 关闭对应连接。

## 安装与使用

打开 `Portly.dmg`，将 **Portly** 拖入 **Applications** 后运行，无需安装 Xcode。

当前构建使用本机临时签名，尚未经过 Developer ID 签名和 Apple 公证。首次启动若被 macOS 拦截，确认来源可信后，可在「系统设置 → 隐私与安全性」中允许打开。

启动后，在「概览」开启需要的连接。窗口关闭后，可从菜单栏的 **Open** 重新打开；选择 **Exit** 退出并断开连接。启动时默认不自动连接。

### 配置 SSH

Portly 使用系统 `/usr/bin/ssh`、`~/.ssh/config` 和 SSH agent。先在自己的 SSH 配置中添加以下两个别名，将示例域名、用户名、端口及密钥路径替换为实际值：

```sshconfig
Host aws-proxy
    HostName aws.example.com
    User your-user
    Port 22
    IdentityFile ~/.ssh/id_ed25519_aws

Host local-proxy
    HostName local.example.com
    User your-user
    Port 22
    IdentityFile ~/.ssh/id_ed25519_local
```

如果已有可用的同名配置，直接沿用即可。建议先在终端验证登录：

```sh
ssh aws-proxy
ssh local-proxy
```

两个连接的默认转发如下，本地入口仅绑定到 `127.0.0.1`：

| 连接 | SSH 别名 | 本地入口 | 远端服务 |
| --- | --- | --- | --- |
| AWS Proxy | `aws-proxy` | `127.0.0.1:17890` | `127.0.0.1:17890` |
| Local Proxy | `local-proxy` | `127.0.0.1:17891` | `127.0.0.1:17891` |

在「设置」中可修改本地端口，远端端口保持固定。保存前需停止两个连接；设置会在下次启动时保留。

## 状态与故障处理

| 状态颜色 | 含义 |
| --- | --- |
| 灰色 | 尚未连接或已手动停止 |
| 橙色 | 正在连接，或监听目标尚未确认 |
| 绿色 | SSH 隧道已连接 |
| 红色 | 连接失败或掉线，需查看原因 |

连接失败后，开关自动关闭，错误保留到重新连接成功或手动清除。在连接卡片中可查看排查建议、展开 SSH 原始错误，或点击「复制错误」。

- **SSH 配置异常**：检查别名、`HostName`、`User`、`Port`、`IdentityFile`，以及配置和密钥文件的格式与权限。
- **认证失败**：检查账号、密钥和 SSH agent，并完成弹窗中的密码或验证码输入。
- **连接被拒、主机不可达或 DNS 故障**：检查服务器 SSH 服务、地址、端口和网络。
- **主机密钥校验失败或变更**：先在终端核对服务器身份，再决定是否更新 `known_hosts`。
- **本地端口被占用**：确认监听该端口的服务，或修改本地端口。每隔 3 秒自动重试，最多两次，首次尝试不计入；也可取消重试。

其他错误需手动重试。手动重试会重新计算重试次数。

### 已有连接与断线检测

发现已有 SSH 监听时，Portly 会核对主机别名与转发参数；匹配后按已连接处理。关闭开关或退出 App 时，会重新核对并关闭对应会话。无法确认目标的进程不会被结束。

Portly 创建的连接通过 SSH 心跳检测断线：每 15 秒探测一次，连续 3 次无响应后退出。已有监听每 3 秒检查一次，消失后尝试重新建立连接。状态反映 SSH 会话是否存在，不代表远端代理服务本身可用。

## 开发与构建

需要完整的 Xcode。运行前先退出旧版 Portly，避免同时运行多个实例。

### Xcode

```sh
open Portly.xcodeproj
```

选择 **Portly → My Mac**，按 **⌘R** 构建并运行，或按 **⌘B** 仅构建。SSH 认证辅助程序会自动打包，无需选择开发团队。

### 命令行

```sh
# 构建 Release 应用
bash build.sh
open build/Portly.app

# 构建并生成 DMG
bash package-dmg.sh
```

产物分别为 `build/Portly.app` 和 `build/Portly.dmg`。DMG 仅包含 App 与 Applications 快捷方式；接收方需自行准备 SSH 配置和密钥。

### 测试

```sh
bash test.sh
```

测试使用模拟 SSH，覆盖连接生命周期、错误分类、重试上限、端口冲突、已有连接识别与关闭，以及配置持久化，不连接真实服务器。实际服务器认证、二次验证和 GUI 交互需在本机验收。
